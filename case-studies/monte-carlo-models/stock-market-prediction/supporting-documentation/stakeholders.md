# Stakeholders

- **Data Scientist / Portfolio Owner:** Builds and validates the simulation logic
- **Hiring Manager / Recruiter:** Reviews code structure, documentation quality, and modeling maturity
- **Quant Analyst / Reviewer:** Evaluates whether GBM assumptions and simulation design are reasonable
- **Platform / MLOps Engineer:** Could productionize scheduling, logging, and artifact storage
- **Business Stakeholder / Investor Persona:** Consumes scenario outputs for directional portfolio understanding
