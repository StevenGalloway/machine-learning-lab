# Problem Statement

Build a portfolio-oriented stock market forecasting case study that demonstrates how a data scientist can simulate a range of future outcomes instead of presenting a single-point prediction. The objective is to estimate likely future portfolio values over a defined forecast horizon using historical market behavior as the input to a stochastic simulation model. For this case study, the selected modeling approach is **Geometric Brownian Motion (GBM)** because it is a widely recognized baseline in quantitative finance and portfolio risk analysis.
