# Stakeholders

## Primary stakeholders
- portfolio reviewers and recruiters evaluating end-to-end ML execution
- hiring managers assessing feature engineering and model-governance maturity
- data scientists reviewing calibration, split logic, and model choice

## Secondary stakeholders
- sports-analytics enthusiasts using the project as a technical reference
- future maintainers extending the feature set or upgrading dependencies

## Success criteria by stakeholder
- recruiters: clear README, clean structure, runnable project
- hiring managers: enterprise-ready organization and artifact generation
- data scientists: reasonable methodology, documented assumptions, and transparent risks
