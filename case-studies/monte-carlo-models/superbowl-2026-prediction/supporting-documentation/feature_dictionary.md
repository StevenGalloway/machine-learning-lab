# Feature Dictionary

## Core feature families

### Offensive efficiency
- `off_epa`: average expected points added on offensive plays
- `off_success_rate`: share of successful offensive plays
- `off_explosive_rate`: share of explosive offensive plays
- `off_turnover_rate`: offensive turnover rate
- `off_sack_rate_allowed`: sack rate allowed by the offense
- `off_pass_rate`: pass-play ratio
- `off_pass_epa`: EPA on passing plays
- `off_rush_epa`: EPA on rushing plays

### Defensive resistance
- `def_epa_allowed`: average EPA allowed by the defense
- `def_success_allowed`: success rate allowed by the defense
- `def_explosive_allowed`: explosive-play rate allowed
- `def_takeaway_rate`: takeaway rate forced by the defense
- `def_sack_rate`: sack rate generated by the defense

### Composite metrics
- `net_epa`: offense minus defense EPA view
- `point_diff`: scoring margin

### Context features
- `rest_days`: days since prior game, clipped to avoid unrealistic values
- `games_played`: number of games already played in season
- `elo_diff`: pregame Elo gap between the teams
- `week`: encoded game week value used during model training and prediction

## Rolling and season features
Each core metric is represented in two forms:
- `_roll8`: trailing rolling average over the last eight games
- `_szn`: season-to-date average using only prior games
