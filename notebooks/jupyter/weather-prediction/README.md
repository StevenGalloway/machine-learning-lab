# Enterprise-Ready Markov Chain Weather Simulation

This project upgrades a simple educational Markov Chain notebook into a more portfolio-ready example.

## What it demonstrates
- Markov property
- state transitions
- transition matrix construction
- stationary distribution estimation
- reproducible simulation
- persisted results for later review

## Project structure
- `markov_weather_enterprise.ipynb` - notebook version
- `markov_weather_enterprise.py` - script version
- `results/` - generated chart and metrics

## Outputs
- `results/weather_state_frequency.png`
- `results/weather_metrics.json`
